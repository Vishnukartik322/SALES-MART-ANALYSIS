# 📊 Sales Mart Analysis – Excel Dashboard

## 📌 Project Overview

This project is an **Excel-based Sales Mart Analysis Dashboard** created to analyze sales data and identify important business insights. The dashboard uses Pivot Tables, Pivot Charts, slicers, and interactive visualizations to present sales performance in an easy-to-understand format.

## 🎯 Objectives

- Analyze overall sales performance
- Understand sales by gender
- Analyze order-wise sales
- Compare sales across different states
- Identify month-wise sales trends
- Analyze sales by customer age group
- Compare sales across different sales channels

## 📈 Dashboard Analysis

The dashboard includes:

- 👨‍🦱 **Gender-wise Sales Analysis**
- 🛒 **Order-wise Sales Analysis**
- 🗺️ **Ship-State-wise Sales Analysis**
- 📅 **Month-wise Sales Trend**
- 👥 **Age & Gender-wise Sales Analysis**
- 🛍️ **Channel-wise Sales Analysis**

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
- Filtering
- Basic Business Analytics

## 🔍 Key Features

- Interactive slicers for filtering data
- Multiple sales performance charts
- Month-wise sales trend visualization
- State-wise sales comparison
- Customer demographic analysis
- Channel-wise sales analysis
